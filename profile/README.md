Reverse engineering Sid Meier’s Colonization — reconstructing the original source code, preserving its behavior, and building modern cross-platform ports.

**Public:**

- [maps](https://github.com/OpenCol/maps) - Archive of community-created maps and scenarios
- [win-decomp](https://github.com/OpenCol/win-decomp) - Reverse engineering and decompilation of the Win 3.1 version of Colonization.
- [win-patches](https://github.com/OpenCol/win-patches) - Community patches for ColWin: animated water, bug fixes and hidden features
- [win31-runtime](https://github.com/OpenCol/win31-runtime) - Play original Colonization Windows 3.1 on a modern OS. Bring your own copy of the game
- [win-tools](https://github.com/OpenCol/win-tools) - Colonization Windows tools for extracting and converting game data
- [web-ui](https://github.com/OpenCol/web-ui) - Shared CSS used across colonization-re projects
- [fsm-to-mp](https://github.com/OpenCol/fsm-to-mp) - Convert FreeCol `.fsm` maps to classic col `.MP` format
- [docs](https://github.com/OpenCol/docs)
- (WIP) [sav-editor](https://github.com/OpenCol/sav-editor) - Savegame editor
